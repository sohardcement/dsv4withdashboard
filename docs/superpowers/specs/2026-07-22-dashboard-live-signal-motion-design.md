# DS4 Dashboard「实时信号层」动效设计

## 状态

用户已确认：在保持浅色黑白灰、信息优先和无巨数背景的前提下，为 Dashboard 补回静态数据时也可感知的节奏。

## 目标与边界

- 让页面在数据未变化时仍传达“连接正常、轮询持续”的生命感；
- 只把变化关联到真实的轮询成功、真实数值变化或用户操作，不伪造吞吐、队列或请求状态；
- 不使用弹跳、循环缩放卡片、彩色流光、飘浮粒子或大面积装饰动画；
- `stale`、`prefers-reduced-motion: reduce` 和移动端连续环境动效必须停止；现有离线语义不变。

## 方案：实时信号层

### 环境节奏

桌面端保留两层无文字灰阶环境光：主光场以约 18 秒的缓慢二维位移运行，阴影层以不同相位的更慢位移运行。它们只改变背景的空间感，不影响文字、布局、透明度或可读性。

### 真实轮询回执

每次成功接收并渲染 `/ds4/status` 快照后，连接圆点和“刚刚更新”文字触发一次短促回执：

- 连接圆点扩出一圈低对比灰阶波纹；
- 时间文本短暂提亮后归位；
- 动效约 620ms，只代表一次已完成的真实轮询；
- 请求失败、数据过期或低动效模式下不触发。

这让静态内容也有可见节奏，同时不暗示数值发生变化。

### 数据反馈

- 真实数值变化继续使用现有的上下方向滚动，保持 420ms；
- 预填充与解码进度条的宽度采用约 360ms 的缓动过渡，而不是跳变；
- 数值未变时绝不重复滚动或闪烁。

### 操作反馈

- 桌面精确指针下，模式切换、筛选控件和主操作获得 160–200ms 的边框、阴影与 1px 位移反馈；
- 调用记录的 hover 仅显示一条低对比引导线；选中仍使用墨线和短距离横移；
- 模式切换采用 280ms 的淡入上移，并与标题/内容使用极轻微错峰，避免整页同时跳动；
- 触摸设备不依赖 hover，仍保留点击和选中反馈。

## 时长与性能约束

| 场景 | 时长 | 约束 |
| --- | ---: | --- |
| 轮询回执 | 620ms | 仅成功快照后触发 |
| 数值滚动 | 420ms | 仅真实值变化 |
| 进度条 | 360ms | 仅进度变化 |
| 操作反馈 | 160–200ms | 仅精确指针 hover / 点击 |
| 模式切换 | 280ms | 不移动页面布局 |
| 环境光 | 18–26s | 桌面、在线、非 reduced-motion 才运行 |

所有连续动效仅使用 `transform`、`opacity`、`box-shadow` 等合成友好属性；不在轮询定时器中强制重排整个页面。

## 验收标准

1. 在线桌面页即使数值不变，连接区能在成功轮询后给出一次可见但低对比的回执；
2. 数值滚动和进度条只在相应真实数据变化时发生；
3. 1440、1024、390px 不出现页面横向滚动、遮挡或布局跳动；
4. `stale`、离线、reduced-motion 和移动端连续环境动效均停止；
5. 模式切换、调用选择、筛选与 KV/上下文交互的现有行为和 API 契约不变；
6. 浏览器回归覆盖轮询回执、数值动效、hover 降级和静止状态。

## 实施范围

- `ds4_server.c`：Dashboard 的内嵌 CSS 与前端渲染逻辑；
- `tests/dashboard_ui_test.js`：动效触发、时长、降级和布局回归；
- 本文档；不改动状态 API、推理逻辑、KV/上下文后端契约。
